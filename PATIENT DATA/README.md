# PATIENT DATA

- `Faiz_Patient_Data_Master_Nov2025-Oct2026.xlsx`: monthly patient sheets (Nov 2025 to Oct 2026) plus a Summary sheet
- `Faiz_Patient_Data_Master_Nov2025-Oct2026.pdf`: printable copy

Every month sheet has a **Bill Amount** column and a monthly bill total. The Summary sheet adds up each month's total.
